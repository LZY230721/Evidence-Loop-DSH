# 证据回路（Evidence Loop）

一个「先交证据、再谈掌握」的学习回路。大多数学习工具记录你完成了什么；这里记录你**改了什么、为什么改、改对了没有**。

## 两种视图

- **我的路径**：三条硬编码路径（概念折叠引擎 A、知识库审计员 B、规则守门人 C）与 14 个学习节点。每个节点带一段「手把手实操指南」和真实环境跳转按钮（Dify / DeepSeek），打开节点就能照着做。`suggested_week` 只以浅色小字显示在节点标题下方，仅作建议节奏，不改变节点颜色、不排序、不计入统计；页面不会出现「逾期 / 落后」字样。
- **审计台**：四块信息——轨迹时间线（重做事件高亮）、质量趋势（四维判定按提交版本序号折线，通过=3/部分=2/不通过=1，可切「全部提交」或「单节点版本」）、重做热区（按重做次数排序）、当前下一步（读取复盘写回的 `next_actions`，点击跳转节点）。

## 状态机（插件代码硬编码）

| 起点 | 触发 | 终点 |
| --- | --- | --- |
| 未开始 | 点击「开始」 | 练习中 |
| 练习中 | 提交作业 | 已提交（自动触发 AI 复盘） |
| 已提交 | 复盘在全部维度判定「通过」，且每个理由都引用了交付物原文 | 已通过复盘 |
| 已提交 | 其他任何判定 | 需重做 |
| 需重做 | 提交新版本且填写 `rework_reason`（少于 5 字无法提交） | 已提交 |

模型只产出复盘 JSON，不能改状态：复盘 JSON 由插件校验（必需维度、判定取值、原文强引用、1–2 条 `next_actions`），通过后由代码计算下一个状态。校验失败时节点停在「已提交」。

## 实操指南与呼叫教练

- 每个节点在 `paths.json` 中带 `tutorial`（手把手步骤）、`tutorial_label` 与 `tutorial_url`（真实环境入口）。旧数据启动时会自动补齐缺失的教程字段，不覆盖你改过的内容。
- 节点详情里的「📋 实战操作指南」直接展示步骤；「🔗 前往实操环境」在新标签页打开 Dify / DeepSeek。
- 「💬 呼叫教练」是节点内的多轮对话：系统提示固定为「只给提示和排查方向，不代写作业、不直接给答案」；上下文带当前节点、通过要求与实操指南。
- 对话按节点保存在 `~/.dsh/evidence-loop/chat/<node_id>.json`，下次打开节点自动恢复；支持「清空对话」。

## AI 复盘

- 每次提交**自动**触发，异步执行：提交立即返回，节点内显示「AI 复盘中…」，完成后状态自动更新。
- 复盘模型使用 profile 的默认模型（`agentDefaultModel`），在设置里更换默认模型即可生效。
- 固定四个维度：完成度、证据充分性、结构清晰度；重做版本（v2 起）额外要求「迭代痕迹」。
- 每个维度的理由必须用引号引用交付物中的原文，插件会逐字校验；引用不到就拒绝整份复盘。
- 解析或校验失败会带原因重试 1 次；仍失败则把错误写到该版本上，界面提供「重新复盘」。
- 单次复盘整体超时 120 秒；记录模型、token 用量与尝试次数到 `reviews/*.json`。

## 外部事实校验

- 只有标记了 `external_check` 的节点（A3、B1、B2、B3、B4、C5）在复盘前会做外部检索；其余节点不联网。
- 检索走 Host 的 `web.search`（和 `web_search` 工具是同一个服务面），检索词只取节点标题与证据要求，**不发送交付物正文**；结果作为**辅助证据**注入复盘提示，并写入复盘记录的 `evidence_refs`（含查询词、标题、链接、片段）。
- 外部证据不得作为「通过」的唯一依据；检索失败不会阻断复盘，只在复盘里记录原因。
- 复盘的 `evidence_refs` 只保存插件实际检索到的来源，不接受模型自填的 URL。

## HR 视角只读分享页

- 审计台底部「HR 分享页」：填写「我从这次重做中学到了什么」→ 点「生成并发布只读链接」。
- 生成一个自包含 HTML（无脚本、无外部资源），内容只有：最近最多 3 次关键重做（每个节点取最近一次）的前后对比、按最弱维度归因的 Bad Case 台账（计数 + 典型一条）、学习者心得。
- 分享页只展示摘要片段（每条 ≤80 字）、复盘判定与修改理由；短交付物不会因为「摘要等于全文」而泄露原文。
- 发布走 Host 的 `shareLink.createPathShare(path, { title, ttlHours })`，**不传 channel**；这与 `share_artifact` 工具内部调用完全一致。默认有效期 7 天，可在分享工具里撤销。
- 发布失败（例如隧道被网络阻断）不影响本地 HTML 生成：界面始终提供一条**本机预览**链接（同源只读，可直接打开），并提示失败原因。

## 数据存放

所有数据写在本地文件，重启 DSH 不会丢：

```
~/.dsh/evidence-loop/
  paths.json          路径与节点（含 suggested_week / status / versions / external_check）
  submissions/        每次提交的版本快照
  reviews/            每次复盘的完整记录（含判定、引用、外部证据、模型与用量）
  rework-reasons/     每次重做的修改理由
  chat/               每个节点的教练对话
  share-note.json     学习者写给分享页的心得
  share/              生成的分享页 HTML 快照
  audit-log.json      状态流转、复盘、外部校验与拦截事件的追加日志
```

同一节点重复提交不会覆盖旧版本；每次提交生成 `v{n}` 新快照，并保留上一版的复盘与修改理由。

## 连续学习与段位

- 连续学习天数只在「提交」时计数（同一天多次提交算一天），中断后显示 0 天。
- 路径完成度、段位（观察者 / 拆解者 / 搭建者 / 审计者）只统计「已通过复盘」的节点。

## 故障排查

- **面板顶部出现「面板与宿主版本不一致」**：浏览器半边已更新，但宿主里的插件代码还是旧版（通常是关闭窗口而不是退出应用，托盘里的进程仍在运行）。请完全退出 DeepSeek Harness（托盘图标 → 退出）后重新打开；仅刷新页面不会重新加载宿主。
- **已提交但很久没有复盘结果**：展开节点，若显示「这个版本还没有复盘记录」就点「开始复盘」补跑；若显示「复盘中…」超过 2 分钟，可点「取消并重新复盘」。
- **复盘失败**：会显示具体原因与「重新复盘」按钮；失败不会改变节点状态，只有合规的复盘 JSON 才会流转。

- **分享页打不开 / 提示「没有建立隧道」**：Cloudflare Quick Tunnel 需要本机直连 `api.trycloudflare.com` 与边缘（7844/443）。浏览器走系统代理，但 cloudflared 不读系统代理；代理开启「TUN / 全局模式」后重试最稳。可先用「本机预览」链接验证 HTML 页面。
- **分享页显示的是 `api.trycloudflare.com`**：这是分享服务旧版把 Cloudflare API 主机误当成隧道地址的上游 bug。本插件会识别并撤销这种无效记录，不再展示坏链接。

## 当前阶段限制

- 分享链接默认 7 天有效，到期或撤销后不可访问；生成的 HTML 快照不会随数据更新。
- 外部校验只在标记节点执行，检索结果仅作辅助证据；搜索服务不可用时复盘仍继续，并记录原因。
- 复盘失败不会自动无限重试，需要你在节点内手动点「重新复盘」，避免消耗额度。
